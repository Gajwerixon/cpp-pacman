# Pac-Man in C++
A Pac-Man game developed in C++ using SFML.

This is a learning project focused on improving C++ programming skills, practicing object-oriented programming, and applying good software engineering practices.

## Project Goals
- Improve C++ programming skills.
- Practice object-oriented programming and class design.
- Learn to organize a C++ project using CMake.
- Practice Git branching, meaningful commits, and version control.

## Development Plan
1. [X] Set up the project structure and build system.
2. [X] Create an SFML window and the main game loop.
3. [ ] Implement the game map and player movement.
4. [ ] Add walls, collectibles, and collision detection.
5. [ ] Implement ghosts and basic enemy behaviour.
6. [ ] Add scoring, lives, and game states.
7. [ ] Improve the gameplay and document the project.

## Technologies
- **C++17** — programming language.
- **SFML** — graphics, input, and multimedia.
- **CMake** — build system configuration.

## Project Status
Early development — project structure and initial setup.

## Learning Focus
The main goal is not only to create a playable game, but also to learn how to design, organize, build, and maintain a C++ application using good software engineering practices.
